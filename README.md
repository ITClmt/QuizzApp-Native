# Quizzly — Front

Client mobile (Expo / React Native) d'une app de quiz : sessions chronométrées, XP, niveaux, avatars à débloquer, classement. L'API backend est dans [`QuizzApp-Back`](../../QuizzApp-Back).

Projet perso avant tout **prétexte pour apprendre** :
- React Native / Expo en profondeur (navigation, state, i18n, animations, build natif...) sur une vraie app
- un workflow de développement assisté par IA (Claude Code et consorts) mené jusqu'au bout sur un projet réel — mémoire de contexte (`CLAUDE.md`/`PRODUCT.md`/`DESIGN.md`), délégation à des agents, revue de code, itération en boucle

Stack : Expo, React Native, TypeScript, React Navigation, React Query, i18next.

## Démarrer


```bash
npm install
npx expo start
```
